# Maldivian Roblox Booking System - Simple Static Version

This version does NOT need Replit, Discord OAuth, Firebase, or GitHub.

## How to use
Open `index.html` in your browser, or upload the folder to Netlify / Tiiny Host / Neocities.

## Features
- 0 Robux pricing
- Passenger form with Roblox username + Discord username
- Admin flight scheduling
- Auto seat assignment
- Add/remove/block seats
- Passenger list / manifest
- Boarding pass cards

## Important
This is a simple static website. Data is stored in the browser using localStorage.
If you open it on another device/browser, the data will not be shared.
For a real shared system later, use Firebase or Supabase.
